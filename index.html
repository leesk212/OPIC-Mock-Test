실전 규칙

5초 안에 한 번만 다시 듣기, 7번 뒤 난이도 재조정

▶을 눌러 질문을 듣고, 끝나는 순간부터 답변 시간이 흘러요. 2분이 넘으면 다음으로 넘어가라는 안내가 떠요.

  • 기본 3문항 랜덤 (약 8분) — 매일 습관용
  • 14·15번 어드밴스 집중 · 롤플레이 11–15 · 실전 15문항 40분
녹음

“목소리가 들려요” — 녹음되는지 눈으로 확인

말하면 볼륨 막대가 오르내리고 초록 상태줄이 켜져요. 실시간 받아쓰기가 그대로 첨삭 재료가 돼요.

  • 문항별 녹음 파일(.webm) 저장 · 다시 듣기
  • 자연스러운 음성(Natural · Neural · Google) 자동 선택
첨삭

내 답변 그대로 고친 AL 버전

예상 등급과 유창성, 문항마다 AL을 막는 2가지, 문장 교정, 재답변 미션, 외워 둘 문장 5개. 없는 경험을 지어내지 않고 내 이야기로 고쳐 줘요.

첨삭은 구독 없이도 돼요

채점 기준은 하나(ACTFL Advanced Low 기준을 구체적인 체크리스트로 바꾼 것). 엔진만 골라 쓰면 결과 화면은 똑같아요.

방법하는 일비용
복사 · 붙여넣기 (기본)“채점 프롬프트 복사” → Claude·ChatGPT·Gemini 아무 채팅에 붙여 넣기 → 답을 다시 붙여 넣기무료
내 API 키시험 직후 자동 채점 (Anthropic · OpenAI). 키는 내 브라우저나 내 컴퓨터에만 저장API 사용료
